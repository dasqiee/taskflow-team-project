
# TaskFlow — Task Management Web Application

## 1. Project Overview

TaskFlow is a web application designed to help individuals and teams create, organize, and manage tasks efficiently.

The project is developed as part of Practical Work #4 — Team Collaboration: Project Initialization and Setup.

## 3. Technology Stack

- React — user interface development
- Vite — development server and production build
- JavaScript — application logic
- CSS — application styling and responsive design
- ESLint — JavaScript and React code quality
- Stylelint — CSS code quality
- Git and GitHub — version control and collaboration

## 4. Project Goals

- Develop an intuitive task management interface.
- Support creating, editing, and deleting tasks.
- Provide task status management.
- Implement task filtering.
- Support responsive layouts.
- Establish a maintainable project structure.

## 5. Development Setup

### Requirements

- Node.js
- npm
- Git

### Installation

```bash
git clone https://github.com/dasqiee/taskflow-team-project.git
cd taskflow-team-project
npm install
```

### Run Development Server

```bash
npm run dev
```

### Code Quality Checks

```bash
npm run lint
npm run lint:css
```

### Production Build

```bash
npm run build
```

## 6. Team Collaboration Workflow

The team uses GitHub for collaborative development.

1. Create a GitHub Issue for each task.
2. Assign the task to a team member.
3. Create a separate Git branch.
4. Implement changes and commit them.
5. Push the branch to GitHub.
6. Open a Pull Request.
7. Request a review from another team member.
8. Merge approved changes into main.
9. Synchronize local repositories.
